01 · About Me

Hello, I'mKrex Simsiman.

I am an aspiring web developer from Nabunturan, Davao de Oro, Philippines. I enjoy turning ideas into useful software, from school record systems to simple tools that make everyday tasks easier. I am currently improving my skills through personal projects and hands-on practice, with a focus on web development.

I studied at Legacy College of Compostela, where I first discovered programming through simple class activities. That encouraged me to learn more about web development and programming outside the classroom, so I keep practicing by following tutorials, experimenting with ideas, and building small projects to improve my skills.

A lot of my early exposure to computers came from curiosity more than formal training, taking things apart (digitally, and sometimes literally) just to understand how they worked. That habit carried over into how I learn to code now: I'd rather break something on purpose and figure out why it broke than just follow a tutorial word for word.

I usually start any new idea on paper before touching code, a rough sketch of the layout, then a short list of the features I actually need for a first version, then build in small, working pieces instead of trying to finish everything at once. Most of my day-to-day work happens in VS Code, with Git and GitHub for version control. Right now I'm focused on getting more comfortable with JavaScript beyond the basics; longer term I want to explore a backend language and a database so I can build full projects instead of front-end-only pages.
